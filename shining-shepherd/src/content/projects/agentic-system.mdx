It runs on my Windows workstation and carries my daily work on StreakUp, Theophonia, research and this portfolio. Claude and Codex both work inside it under the same rules, memory and tools. The model is the part I can swap. The workspace is the part that remembers.

<Band id="memory" n="01" kicker="Memory" tone="archive" title="Finding the source of a decision" lede="Echo lets an agent look up the original conversation. Hippocampus lets it retrieve a rule, decision or procedure in the words of the current task.">

<SessionRecall />

<Notes>

- **Two stores, two jobs.** Echo keeps what was actually said. The curated layer, Hippocampus, keeps what was decided: rules, facts, decisions and procedures.
- **Hybrid retrieval.** Keyword search and vector search run side by side. Their result lists are fused by rank, then a diversity pass trims near duplicates.
- **Full mechanics** of ranking and freshness are in the [Hippocampus case study](/projects/hippocampus).

</Notes>

</Band>

<Band id="rules" n="02" kicker="Rules" tone="routes" title="Rules arrive with the subject" lede="“Review this” means different work for an animation, a screen or a story. So only a thin layer of rules is always loaded; the rest is fetched when the subject calls for it.">

<RuleRoutes />

<Notes>

- **Described for a Codex session.** A startup hook loads the current safety and communication rules; every new request carries a short reminder.
- **Procedures live in my Brain database.** The agent describes the task and retrieves the matching procedure, or follows the project map or a named workflow to its guide.
- **Retrieval narrows again inside a subject**, as the second lines in the table show.

</Notes>

</Band>

<Band id="team" n="03" kicker="Team" tone="network" title="A team with distinct jobs" lede="No single model does everything. Two session leads share one workspace, specialists get scoped tasks from them, and one person makes the final call.">

<AgentArchitecture />

<CrossReview />

<Notes>

- **Swappable leads.** Claude and Codex run through their own first party command line tools on one provider neutral protocol. Provider specific behavior lives in thin adapters, so switching the lead changes the model, not the rules.
- **Supervised worker.** When Codex hands Qwen an edit, a heartbeat records Qwen’s activity without copying the prompt or source code into the monitoring log.

</Notes>

</Band>

<Band id="context" n="04" kicker="Context" tone="measure" title="A smaller starting context" lede="Loading fewer instructions leaves more room for the work. I tested whether the smaller project map still led the agent to the right files.">

<ContextBudget />

<Notes>

- **Before.** My earlier workspace loaded a large map of every project up front, whether the task touched them or not.
- **After.** A small root map routes the agent to topic material when the task needs it.
- **The test.** Size alone was not the goal, so I also checked whether the smaller map still led to the right material.

</Notes>

</Band>
