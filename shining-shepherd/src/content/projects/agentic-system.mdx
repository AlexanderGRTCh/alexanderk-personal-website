## An AI system built to keep working

A model can answer a prompt. A working engineering system must also recover the right project context, use tools safely, coordinate specialists, survive interruptions, and show what happened.

I built this Windows native environment for product development and the daily work of Ktisis Arc. Claude and Codex run on top of the same provider neutral protocol. The model can change without rebuilding the memory, tools, project rules, or review process around it.

## From request to reviewable work

Boot starts with a lean protocol and a root map. The map points to project indexes, operating rules, skills, and memory routes. The agent opens only the context required for the current task.

When earlier decisions matter, the [Hippocampus memory layer](/projects/hippocampus) combines keyword and semantic retrieval. MCP servers and local scripts connect the agent to files, services, commands, and structured tools. Specialist agents can work on bounded parts of a larger task while a primary agent owns the final integration.

For sensitive or complex artifacts, Claude and Codex can review the same work from different provider perspectives. Findings use a shared schema, similar issues are clustered, and bounded rounds stop when another pass adds nothing material. Accepted decisions enter a durable log.

## The engineering underneath

Python coordinates the platform. SQLite stores memory, transcript indexes, task state, and run history. FTS5 and sqlite vec support hybrid retrieval. MCP gives models a consistent tool boundary. Windows services and scheduled tasks run background capture, health checks, and recovery jobs.

A persistent run ledger allows interrupted workflows to resume. Duplicate work checks prevent accidental parallel copies. A cost circuit breaker limits bounded operations. Heartbeats and liveness checks surface work that has stalled instead of leaving it invisible.

Raw conversations enter a separate searchable archive. An hourly watcher extracts useful facts, decisions, and procedures after sessions become idle, with a daily backstop. The curated memory remains focused while the original record stays available.

## Measured context reduction

The earlier workspace map loaded **8,316 text tokens**. The replacement root map loaded **773**, a **90.7 percent reduction** at the September 7, 2026 implementation snapshot.

The complete default boot path fell from **13,821 tokens to 2,614**. A cold comparison that included the required lookup routes fell from **16,633 to 5,470**. Sixteen bounded lookup cases exposed one missed route, which I corrected before all sixteen resolved.

This measures context loaded by the protocol. It does not claim a matching reduction in the provider bill, faster responses in every task, or perfect recall.

## Proof through shipped work

The platform is not a dashboard concept. I use it to develop [StreakUp](/projects/streakup-habit-tracker), operate Theophonia, maintain this portfolio, prepare documents, and run recurring checks.

For an employer, it demonstrates AI systems engineering across orchestration, retrieval, tooling, evaluation, observability, and recovery. For a client, it shows the same practical judgment Ktisis Arc brings to business software: automate the repeatable work, preserve the evidence, and keep consequential decisions reviewable.
