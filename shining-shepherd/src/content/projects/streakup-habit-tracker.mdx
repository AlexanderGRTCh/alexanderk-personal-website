## A habit tracker built for real routines

StreakUp helps people repeat small actions without turning every miss into failure. It supports daily habits, weekly goals, one off tasks, reminders, streaks, milestones, and themes. The app is available on <a href="https://play.google.com/store/apps/details?id=com.AlexanderCH.habitracker2026" target="_blank" rel="noopener">Google Play</a> and the <a href="https://apps.apple.com/us/app/streakup-habit-tracker-goals/id6760596379" target="_blank" rel="noopener">App Store</a>.

## What I built

I designed and engineered the product across Flutter, iOS, and Android. Clear home screen cues show what needs attention and what is complete. Streak Shields preserve progress after a missed day when the user returns. Milestones, responsive celebrations, and personal bests make progress visible without hiding the work.

## Engineering approach

Riverpod coordinates reactive state across goals, settings, purchases, and interface updates. Hive stores goals locally, so core tracking remains available without a connection. RevenueCat manages subscription entitlements, while AdMob supports the free experience. Local notifications let people act on reminders and process responses after reopening.

The code separates domain, data, and presentation concerns for easier maintenance. Shared Flutter code supports both platforms while preserving platform specific release requirements.

I also handled store packaging, release coordination, and platform specific configuration.
