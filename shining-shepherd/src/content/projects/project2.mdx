## A match model you can inspect

This Python simulator turns tennis scoring and momentum into an interactive court view. Each point updates the score, momentum, and probability shown to the user. A seed makes the same planned match and visual sequence repeatable.

## What I built

The engine owns scoring, serving, momentum, bias, and point sampling. An adapter converts engine events into a compact stream for the viewer. Pygame renders the court, players, ball paths, score, and current bias. Keyboard and mouse controls advance play, change speed, or replay the latest point.

## Engineering approach

The probability model starts from the chosen bias and adjusts for momentum. Point, game, and set outcomes contribute different amounts. The final value is clamped before server advantage and random sampling are applied.

Visual planning uses the same seed as the match. The viewer caches the latest point plan for exact replay. This separation keeps scoring independent from rendering and makes unexpected behavior easier to reproduce.

The interface also keeps internal state visible while each point unfolds.

## Result

The project combines probability, match rules, event flow, animation, and user input. It works as a focused simulator and engineering demonstration. Seeded behavior makes examples repeatable for debugging, teaching, and experimentation.
