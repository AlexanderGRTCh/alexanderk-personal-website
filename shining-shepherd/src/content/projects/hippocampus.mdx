## Remember the decision, keep the source

Repeating the same background wastes time. Loading every past conversation makes the next task harder to focus on.

Hippocampus is the memory layer inside my [Agentic System](/projects/agentic-system). It keeps concise facts and decisions alongside a separately searchable conversation archive. That gives me a focused starting point and a route back to the original context.

## Why one search is not enough

A filename needs an exact match. A question about a past decision may use different words. I combine both search methods, then reduce repetitive results.

Memory also ages differently. An operating rule should remain useful longer than a temporary task update. The ranking considers memory type, importance and freshness alongside relevance.

The result is a system I use to recover project context. Retrieval can still miss something important, so source inspection remains part of the workflow.

<details>
<summary>Engineering decisions</summary>

Python coordinates FTS5 keyword search and cosine vector search through the SQLite vector extension. Reciprocal rank fusion merges their rankings. Maximal marginal relevance reduces repetition before the final selection.

Curated memory and transcript tables share one SQLite database, but use separate retrieval paths. An archive search is explicit. Stored facts and exact conversation text serve different needs.

Freshness uses exponential decay with constants chosen by memory type. These constants are decay windows, not mathematical half lives. Vector lookup uses exact distance search; this implementation does not claim approximate indexing at large scale.

Storage is local. Creating query embeddings can call a cloud service, so retrieval is not fully offline. A further reranking stage exists, but is optional and documented as dormant.

</details>

## Built for a real working environment

This architecture comes from my daily working environment, with private records excluded. It demonstrates retrieval design and its tradeoffs. It is not a promise of perfect recall or a publicly released memory service.
